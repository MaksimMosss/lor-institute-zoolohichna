# Інститут отоларингології — інформаційний лендінг

Незалежний дизайн-концепт для відвідувачів Інституту отоларингології ім. проф. О. С. Коломійченка. Це не офіційний сайт медичного закладу.

## Файли

- `index.html` — сторінка та контент;
- `style.css` — адаптивна верстка, анімації та стани інтерфейсу;
- `app.js` — меню, пошук лікарів і форма-маршрутизатор;
- `dist/` — готовий пакет для початкового розгортання на Sites.

Сайт не потребує збірки чи встановлення залежностей.

## Публічний перегляд через GitHub Pages

Репозиторій: https://github.com/MaksimMosss/lor-institute-zoolohichna

Щоб опублікувати сторінку: відкрийте **Settings → Pages → Build and deployment**, виберіть **Deploy from a branch**, гілку **main**, теку **/(root)** і натисніть **Save**. GitHub описує ці кроки в [інструкції з налаштування джерела публікації](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

Після завершення публікації сторінка буде доступна за адресою:

https://MaksimMosss.github.io/lor-institute-zoolohichna/

## Що є в макеті

- адаптивна верстка для телефонів, планшетів і широких екранів, мобільне меню та панель швидких дій;
- легкий анімований екран завантаження з підтримкою налаштування reduced motion;
- покрокова форма-маршрутизатор для вибору напряму й перевіреного контакту;
- профілі лікарів, напрями лікування, блок ЛОР-онкології, підготовка до візиту, історія, відгуки й контакти;
- пошук лікарів, клавіатурна навігація та пояснення, що медичну інформацію треба підтвердити безпосередньо в закладі.

## Форма запису

Форма — інтерактивний прототип. Вона нічого не надсилає та не зберігає; після вибору напряму підказує контакт, щоб завершити запис телефоном. Для приймання справжніх заявок потрібне окреме погоджене з інститутом підключення форми й політики обробки персональних даних.

## Фото та джерела

Портрети завантажуються з публічних профілів на офіційному сайті інституту. Факти й посилання на джерела наведені в самому лендінгу, у розділі «Джерела та редакційні примітки». Розклад, контакти й доступність прийому можуть змінюватися — звіряйте їх з офіційним сайтом перед візитом.
