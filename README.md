# Інститут отоларингології — інформаційний лендінг

Незалежний дизайн-концепт сторінки для відвідувачів Інституту отоларингології ім. проф. О. С. Коломійченка. Це не офіційний сайт медичного закладу.

## Перегляд

Відкрийте `dist/index.html` у браузері. Сторінка не потребує збірки чи встановлення залежностей.

## Що є в макеті

- адаптивна верстка для широких і вузьких екранів, мобільне меню та панель швидких дій;
- анімований екран завантаження з підтримкою налаштування reduced motion;
- покрокова форма-маршрутизатор для вибору напряму й перевіреного контакту;
- профілі лікарів, напрями лікування, окремий блок ЛОР-онкології, підготовка до візиту, історія, відгуки та контакти;
- пошук лікарів, клавіатурна навігація та пояснення, що медичну інформацію треба підтвердити безпосередньо в закладі.

## Форма запису

Форма поки є інтерактивним прототипом. Вона нічого не надсилає та не зберігає; після вибору напряму підказує контакт, щоб завершити запис телефоном. Для приймання справжніх заявок потрібне окреме погоджене з інститутом підключення форми й політики обробки персональних даних.

## Фото

Портрети завантажуються з публічних профілів на офіційному сайті інституту. Для незалежного розгортання перевірте умови використання та доступність цих зображень.

## Джерела контенту

Основні факти й посилання на джерела наведені в самому лендінгу, у розділі «Джерела та редакційні примітки». Розклад, контакти й доступність прийому можуть змінюватися — звіряйте їх з офіційним сайтом перед візитом.

## Локальне відкриття

На Windows двічі натисніть `dist/index.html`. Або запустіть будь-який локальний статичний сервер із теки `dist`.
